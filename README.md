# ☕ Wake & Lake – Fictional Lakeside Café Website

Welcome to **Wake & Lake**, a responsive website for a peaceful lakeside café. It is designed to give visitors a calm, simple and pleasant browsing experience.

> **Note:** Wake & Lake is a **fictional café** created for this web development project. The address, phone number, email, menu, prices, and customer reviews are sample content only.

## 🌐 Live Website

👉 [Visit Wake & Lake](https://shreya-k09.github.io/A-cafe-website/)

## 📌 About the Project

Wake & Lake is a front-end website project built with HTML, CSS, and JavaScript. It showcases an imagined café's story, menu, atmosphere, reviews, and reservation and contact details through a clean, user-friendly design.

## ✨ Features

- Responsive design for desktops, tablets, and phones
- Mobile-friendly navigation menu with smooth section links
- Attractive homepage with a hero section
- "Our Story" section about the café
- Food and beverage menu with category filters (All, Coffee, Cold Drinks, Desserts, Bakery) and sample prices in BDT
- Photo gallery showing the café atmosphere
- Sample customer reviews section
- Table reservation form (name, email, date, time, number of guests)
- Contact information section
- Newsletter subscription section
- Opening hours
- Social media links

## 🛠️ Technologies Used

- **HTML5** – page structure
- **CSS3** – styling and responsive layout
- **JavaScript** – interactivity

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shreya-k09/A-cafe-website.git
   ```

2. Go into the project folder:

   ```bash
   cd A-cafe-website
   ```

3. Open `index.html` in your web browser.

No installation or build steps are needed.

## 🚀 Deployment

This website is hosted using **GitHub Pages**. Changes pushed to the main branch are published automatically at the live link above.
